# Tech

## Stack

- Python 3.11+, FastAPI + uvicorn.
- pytest for tests; ruff for linting (config pinned in `ruff.toml` at repo root).
- torch + librosa for ML (50–500 Hz log-mel spectrograms).
- Plain JS + Leaflet (CDN) for the frontend, no framework.
- Amazon Bedrock via boto3 Converse for the brief.

## Environment

- Use the project venv (`.venv`), not conda base.

## Dependencies

- No extra frameworks or dependencies without asking.
