# Tech

## Stack

- **Language:** Python 3.11+
- **Backend/API:** FastAPI
- **ML / audio:** torch, librosa, soundfile, scikit-learn
- **AWS / LLM:** boto3 (Amazon Bedrock)
- **Frontend:** plain JavaScript + Leaflet

## Constraints

- No extra frameworks. Do not introduce additional frontend or backend
  frameworks beyond those listed above.
- Keep code simple and runnable. Prefer straightforward, readable code over
  clever abstractions.
- Keep files small. Favor small, focused modules over large ones.
